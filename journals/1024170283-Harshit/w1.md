EduOS Development Journal - Week 1
==================================

**Project:** EduOS - Academic Computing Platform\
**Week:** Week 1

Overview
--------

This week, I focused mainly on understanding the architecture and development workflow planned for EduOS. The project uses an Arch Linux base, with Archiso being used to create a customized bootable image.

I helped examine the initial Archiso configuration and understand how the different profile files control the contents of the operating system.

We also set up QEMU/KVM for testing and confirmed that the generated ISO could boot successfully in a virtual machine. This gave us a safe environment for experimenting with EduOS without changing the main operating system.

Work Completed
--------------

-   Studied the Archiso profile structure.
-   Helped configure the initial EduOS repository.
-   Tested the first generated ISO in QEMU.
-   Checked virtualization support and required tools.
-   Helped with the initial system design and UML diagrams.

Conclusion
----------

By the end of the week, we had a functional development environment and a reliable way to build and test EduOS using a virtual machine.
