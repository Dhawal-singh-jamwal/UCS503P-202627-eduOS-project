EduOS Development Journal - Week 2
==================================

**Project:** EduOS - Academic Computing Platform\
**Week:** Week 2

Overview
--------

This week, I focused on testing and troubleshooting the graphical environment being added to EduOS. The team integrated XFCE along with Xorg and LightDM into the Archiso image.

We tested the graphical login process in QEMU and encountered problems where the desktop session would return to the LightDM login screen. We investigated the issue using the VM's TTY and system logs.

We also worked on configuring the default `eduos` account and making sure it was created automatically during boot. After fixing the required permissions, the account appeared correctly in LightDM.

A direct test of XFCE from the TTY confirmed that the desktop itself was working, leaving the LightDM-to-XFCE session startup as the main issue to investigate.

Work Completed
--------------

-   Tested the new XFCE graphical environment.
-   Helped troubleshoot LightDM login problems.
-   Investigated systemd service failures.
-   Tested the `eduos` account inside the VM.
-   Verified Xorg and XFCE independently.
-   Helped identify the remaining LightDM session issue.

Conclusion
----------

The graphical environment is now mostly functional. XFCE can successfully run inside EduOS, while further work is required to make LightDM launch the XFCE session reliably.
