EduOS Development Journal - Week 1
==================================

**Project:** EduOS - Academic Computing Platform\
**Week:** Week 1

Overview
--------

This week, I worked on understanding the EduOS project structure and helping establish the initial development environment. We decided to use Arch Linux as the base and Archiso to generate our custom operating system image.

I helped verify the required virtualization and development tools and tested the initial Archiso profile inside QEMU/KVM.

The first bootable ISO was successfully generated and launched in a virtual machine, allowing us to test EduOS without modifying the host system.

I also reviewed the planned system functionality and contributed to the initial UML diagrams and project planning.

Work Completed
--------------

-   Reviewed the EduOS project requirements.
-   Helped set up the Archiso-based project structure.
-   Tested ISO generation and QEMU/KVM booting.
-   Verified that the OS could be tested safely inside a VM.
-   Contributed to initial project diagrams and planning.

Conclusion
----------

The first week established the basic development and testing workflow for EduOS. The team now has a working method for building and testing the operating system safely.
