
EduOS Development Journal - Week 2
==================================

**Project:** EduOS - Academic Computing Platform\
**Week:** Week 2

Overview
--------

During Week 2, I worked on the desktop environment and user setup of the EduOS image. We added XFCE and the required graphical components to the Archiso package configuration.

We also configured LightDM as the display manager and worked on creating the default `eduos` user automatically during system startup.

Several issues appeared during testing, particularly with permissions and the startup service. These were investigated using the QEMU console and system logs.

After correcting the configuration, we were able to log into the XFCE desktop successfully through LightDM.

Work Completed
--------------

-   Added XFCE and graphical packages to the EduOS image.
-   Configured LightDM and its greeter.
-   Worked on automatic `eduos` user creation.
-   Debugged systemd service and permission problems.
-   Tested login and XFCE startup inside QEMU.
-   Verified that the graphical desktop could be launched successfully.

Conclusion
----------

Week 2 focused on turning the basic Archiso environment into a usable graphical EduOS system. The successful XFCE login confirmed that the desktop environment was functioning inside the virtual machine.
